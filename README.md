Celestia Astrocosmos Add-on

This Repository was made to store translated Astrocosmos's Celestial Object as Celestia data files.
The main flow of this repo is just to be copy and pasted into the Celestia `extras/` directory

it is confirmed that you can run scripts, so we can put this directly into extras, but the script wont be automatic. Therefore, the user must re-run Celestia after running the script

Some content of this repository is not meant to be edited directly, since it was translated ("generated") from main Astrocosmos repository

> [!WARNING]
>
> Make sure to backup your original `celestia.cfg` before pasting the content into Celestia root directory
